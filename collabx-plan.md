# CollabX — Planning Document

## Core Idea
A platform where students showcase projects and receive
skill-based endorsements to build real credibility.

## V1 Features
- User authentication (login/signup)
- User profile
- Add and manage projects
- Skill endorsements by peers
- Credibility tiers (Bronze / Silver / Gold)
- Basic dashboard

## Tech Stack
Frontend:
- React

Backend:
- Node.js
- REST APIs

Database:
- PostgreSQL (Supabase)

## Goal of V1
Prove that student work + endorsements can act as a
lightweight credibility signal.
